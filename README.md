# Portafolio | Alexis Castillo Netzahualcoyotzi

Portafolio web profesional de Alexis Castillo Netzahualcoyotzi.
Este sitio reúne una selección de mis proyectos, experiencia, formación, habilidades técnicas y medios de contacto. Fue diseñado con una interfaz moderna, responsiva y fácil de navegar.

## Características

- Diseño responsivo para computadoras y dispositivos móviles.
- Navegación por las secciones principales del portafolio.
- Presentación de proyectos profesionales y académicos.
- Apartado de experiencia, formación y habilidades.
- Animaciones discretas y una terminal simulada mediante JavaScript.
- Acceso al currículum, correo, GitHub y LinkedIn.
- Estructura desarrollada con HTML semántico, CSS y JavaScript.

## Secciones

- **Inicio:** presentación y perfil profesional.
- **Proyectos:** selección de trabajos y proyectos relevantes.
- **Acerca de mí:** trayectoria, experiencia e intereses profesionales.
- **Currículum:** resumen de formación y experiencia.
- **Contacto:** enlaces para comunicarse conmigo.
